# virtual-lab – Phòng thí nghiệm Vật lý ảo

Các mô phỏng tương tác (SVG/Canvas) theo từng bài học. Mỗi thí nghiệm gồm: dụng cụ trực quan, thanh trượt thông số có giới hạn, số đo, công thức, đồ thị, nút Bắt đầu/Tạm dừng/Đặt lại, hướng dẫn, câu hỏi sau thí nghiệm, lưu kết quả (`experiment_attempts`).

Trạng thái: **chưa triển khai** (Milestone 2).
